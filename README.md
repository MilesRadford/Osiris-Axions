-------------OSIRIS + AXIONS-------------------  
  
This package adds axion production through Brehmsstrahlung, Compton scattering and Primakoff production to the OSIRIS pic code.  
It is based upon the OSIRIS  
  
------------Contents--------------------------  
  
---physics---  
  
os-a_brems                    ----Contains axion creation via Bremsstrahlung  
os-a_compt                    ----Contains axion creation via Comptons scattering  
  
---particle species---  
  
os-axions.f03                 ----Contains functions to advance axions and for axions to decay via Primakoff process  
os-axions-define.f03          ----Contains definitions of axion particle species  
os-axions-diagnostics.f03     ----Contains means to produce axions data output
